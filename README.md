# One Line, One Laugh

One original funny line for the make.fun bounty "One Line, One Laugh": a program that writes a single joke to `/output/entry.txt`.

The joke: a customer asks a barista for something strong, and the barista answers with a mirror — the strongest thing in the room is the customer's own face.
